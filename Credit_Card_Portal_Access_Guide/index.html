Credit Card Portal Access Guide

IT Applications involved: PI0311, PXG011 & Portal

Step 1: Open OneIDM

Go to the OneIDM link:

https://oneidm.bosch.com/oneidm/html/rbwebshop/#/start/itshop/VI_Start

  • Click Request → New Request
  • Search for requester NT ID in the Recipients Field and select the requester

Step 2: Add PI0311 Roles

  • Search for IT Application PI0311 and click on it
  • Search for default roles in Services:
    • X:H5TM_XXXX_MIN_USER → Check box → Add to Shopping Cart
    • X:H5TM_XXXX_RBEI_EMPLOYEE → Add to Shopping Cart

Step 3: Add PXG011 Role

  • Search for IT Application PXG011 and click on it
  • Search for default role in Services:
    • X:0GHR_FIORI_TRV_RBEI_PI0 → Check box → Add to Shopping Cart

Step 4: Add Portal Role

  • Search for IT Application Portal and click on it
  • Search for default role in Services:
    • CN=rb_flp_swift_trv_grp,OU=portal,OU=groups,OU=esi,DC=wam-bosch,DC=com → Check box → Add to Shopping Cart

Step 5: Submit Request

  • Click the Shopping Cart symbol (top right corner)
  • Check all boxes for the selected roles
  • Enter a Justification
  • Click Save → Order

A Combined Request ID will be generated. The requester will be notified via email from identity.manager@de.bosch.com with the subject: oneIDM info: request submitted.
