SWIFT Access Troubleshooting Guide

If you are unable to access the SWIFT Application, there are several possible reasons:

  • Not using SWIFT application for longer than 6 months or the SWIFT system may not be available for the user.
  • Password for PI0 application may have expired (after 1 year or more).
  • PI0311 account might have been deactivated.
  • Browser cache needs to be cleared.

Case 1: SWIFT Application Not Used for More Than 6 Months / System Unavailable

Follow these steps to check the available roles in OneIDM for your account:

Step 1: Check Roles in OneIDM

Go to OneIDM using the link below:
https://oneidm.bosch.com/oneidm/html/rbwebshop/#/start/itshop/VI_Start

  • Click on Requests → Extend or Revoke
  • In the IT Application column, search for PI0311
  • Click on the filter in Services column and enter the first role X:H5TM_XXXX_MIN_USER → Click Search
  • Then, repeat for the second role X:H5TM_XXXX_RBEI_EMPLOYEE → Click Search

If both roles are available but access is still not working, check if the PI0311 account is active and if a password change is required.

Step 2: Account Activation & Password Change

Go to OneIDM using the below link for account activation:
https://oneidm.bosch.com/oneidm/html/rbwebshop/#/start/itshop/VI_Start

Activate Account (if ⚠️ symbol appears):

  • Navigate to Accounts → My Accounts → PI0311 → Activate
  • Note down the CRN (Combined Request Number)

Track Request Status in OneIDM:

  • Go to Requests → Find Requests
  • Filter with the Combined Request ID
  • Enter your CRN number and click Search
  • Workflow status should change from Processing → Successful

If workflow does not complete (stuck in processing), raise an IT Service Desk ticket using the link below:

https://rb-servicecatalog.apps.intranet.bosch.com/RequestCenter/website/Grunt/application/itsupport.html
Note: You will receive a notification email from identity.manager@de.bosch.com once the workflow is successfully completed.

Step 3: Reset Password (if required)

  • Go to Accounts → Change Password
  • Search for IT Application PI0311 and click on it
  • In the Password column, enter a new password as per policy
  • Click Submit

A new Combined Request ID will be generated after submission.

Step 4: Clear System Cache

  • Open your browser settings and clear the cache.
  • Restart your browser and try again.
  • If the issue persists, use an alternate browser.
