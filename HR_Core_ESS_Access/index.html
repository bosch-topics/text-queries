HR CORE ESS Access Guide

Please follow the steps below to get access for HR CORE ESS:

Step 1: Open OneIDM

Go to the OneIDM link below:

https://oneidm.bosch.com/oneidm/html/rbwebshop/#/start/itshop/VI_Start

Navigate through the following menu:

  • Click Request → New Request
  • Search for the requester NT ID in the Recipients Field and select it

Step 2: Add PH1011 Roles

  • Search for IT Application “PH1011” and click on it
  • Search for default roles under Services:
    • X:H0SY_XXXX_ALL_M_MINUSER_HR → Check box → Add to Shopping Cart
    • X:H0HR_INXX_MA_ESS → Add to Shopping Cart

Step 3: Add PXG011 Roles

  • Search for IT Application “PXG011” and click on it
  • Search for the following roles under Services and add each to the shopping cart:
    • X:0GFI_FIORI_SSF_MYACC_PDX
    • X:0GXX_FIORI_ALL_MINUSER
    • X:0GHR_FIORI_HCM_IN_HPE_PH1
    • X:0GHR_FIORI_HCM_IN_ESS_PH1
    • X:0GHR_FIORI_TRV_RBEI_PI0

Step 4: Add Portal Roles

  • Search for IT Application “Portal” and click on it
  • Search for the following roles under Services and add each to the shopping cart:
    • CN=org_every_rbei_associate,OU=portal,OU=groups,OU=esi,DC=wam-bosch,DC=com
    • CN=rb_myhr_associate_in,OU=portal,OU=groups,OU=esi,DC=wam-bosch,DC=com
    • CN=rb_fi_myaccounting_self_service_new_ui,OU=portal,OU=groups,OU=esi,DC=wam-bosch,DC=com
    • CN=rb_fi_myaccounting_self_service,OU=portal,OU=groups,OU=esi,DC=wam-bosch,DC=com
    • CN=rb_flp_hr_core_users,OU=portal,OU=groups,OU=esi,DC=wam-bosch,DC=com
    • CN=rb_flp_swift_trv_grp,OU=portal,OU=groups,OU=esi,DC=wam-bosch,DC=com

Step 5: Submit the Request

  • Click the Shopping Cart symbol (top-right corner)
  • Check all boxes for the selected roles
  • Enter a Justification
  • Click Save → Order

A Combined Request ID will be generated, and the requester will be notified via email from identity.manager@de.bosch.com with the subject line: “oneIDM info: request submitted”
