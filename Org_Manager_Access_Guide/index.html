Org Manager Access Guide

IT Applications involved: PH1011, PXG011 & PI0311

Step 1: Open OneIDM

Go to OneIDM:

https://oneidm.bosch.com/oneidm/html/rbwebshop/#/start/itshop/VI_Start

  • Click Request → New Request
  • Search for requester NT ID in Recipients Field and select the requester

Step 2: Add PH1011 Role

  • Search for IT Application PH1011 and click on it
  • Search for required role in Services: X:H0HR_INXX_MA_MSS → Check box → Add to Shopping Cart

Step 3: Add PXG011 Roles

  • Search for IT Application PXG011 and click on it
  • Search for required roles in Services and add to Shopping Cart:
    • X:0GHR_FIORI_HCM_IN_MSS_PH1
    • X:0GAM_FIORI_UIB_AMMGP_PEI
    • X:0GFI_FIORI_UIB_APM_PM7
    • X:0GFI_FIORI_UIB_SWIFT_PI0

Step 4: Add PI0311 Role

  • Search for IT Application PI0311 and click on it
  • Search for required role in Services: X:H5TM_XXXX_RBEI_MANAGER
  • Check all boxes and add to Shopping Cart

Step 5: Submit Request

  • Click the Shopping Cart symbol (top right corner)
  • Check all boxes for the selected roles
  • Enter a Justification
  • Click Save → Order

A Combined Request ID will be generated. The requester will be notified via email from identity.manager@de.bosch.com with the subject: oneIDM info: request submitted.
