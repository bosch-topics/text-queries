Purchase Request Access Guide

Step 1: Open OneIDM

Go to the OneIDM link below:

https://oneidm.bosch.com/oneidm/html/rbwebshop/#/start/itshop/VI_Start

  • Click Request → New Request
  • Search for IT Application PPM011 and click on it
  • Search for roles in Services:
    • X:B0PU_MIP_REQUESTER
    • X:BXXX_STAR_PPM_MINUSER
    • X:B0PU_SMPL_REQUESTER
    Check the boxes and click Add to Shopping Cart
  • Search for IT Application Portal and click on it
  • Search for role in Services:
    • CN=rb_my_i_buy_virtual_company_mall_user,OU=portal,OU=groups,OU=esi,DC=wam-bosch,DC=com
    Check the box and click Add to Shopping Cart

Step 2: Submit Request

  • Click the Shopping Cart symbol (top right corner)
  • Check all boxes for the selected roles
  • Enter a Justification
  • Click Save → Order

A Combined Request ID will be generated. The requester will be notified via email from identity.manager@de.bosch.com with the subject: oneIDM info: request submitted

Step 3: Workflow Status

Workflow status will change from Processing → Successful. Once completed, the requester will receive a notification from OneIDM email ID identity.manager@de.bosch.com with subject line oneIDM info: request completed.
